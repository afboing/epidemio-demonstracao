# Replicar o painel em outra revista

Este material é público e contém apenas dados fictícios.

## Comece aqui

1. Baixe o [pacote completo de código e exemplos](epidemio-demonstracao-compartilhar.zip?raw=true).
2. Descompacte e leia o arquivo **LEIA-ME.md**.
3. Abra **Abrir-demonstracao.html** no navegador para experimentar sem instalação.
4. Consulte o [guia de adaptação](ADAPTAR-PARA-OUTRA-REVISTA.md) e a [planilha-modelo em Excel](Modelo-Artigos-FICTICIO.xlsx?raw=true).

O pacote inclui código editável, cálculos, gráficos, gerador de dados fictícios, importador de Excel, testes e roteiro de apresentação.

[Explorar a demonstração online](https://afboing.github.io/epidemio-demonstracao/).

## Antes de usar dados reais

Revise os cabeçalhos, categorias, denominadores e critérios editoriais conforme sua revista. A implantação real deve ser separada, com autenticação e conexão às próprias fontes. O pacote não contém dados confidenciais, credenciais ou integração com as planilhas da epidemio.

O HTML portátil incorpora sua base completa: use apenas dados fictícios em cópias destinadas a divulgação. Para outra revista, substitua a identidade visual pela marca correspondente.

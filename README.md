# epidemio · demonstração pública

Painel de monitoramento editorial com **810 artigos inteiramente fictícios**. Títulos, pessoas, instituições, datas, contagens e resultados foram inventados; não representam o desempenho real da revista.

O site funciona diretamente no navegador, sem senha, sem servidor de dados e sem conexão com Google Drive ou planilhas. A referência inicial é fixa em **19/11/2026** para permitir apresentações reproduzíveis.

## Explorar e compartilhar

Abra a página publicada pelo GitHub Pages deste repositório. Use os filtros e o botão **Reiniciar demonstração**. O aviso de dados fictícios permanece visível durante a navegação.

[Baixar código, planilha-modelo e guia de adaptação](epidemio-demonstracao-compartilhar.zip).

O pacote inclui as regras dos indicadores e orientações para adaptar cabeçalhos, categorias e critérios editoriais a outra revista. A marca epidemio identifica a experiência original; outras revistas devem usar sua própria identidade visual. A malha simplificada do mapa tem atribuição ao IBGE no painel.

## Manutenção

`index.html` é a versão portátil completa, com gráficos, logo e dados sintéticos incorporados. Para atualizar, regenere o HTML no projeto de demonstração e substitua somente este arquivo. O pacote de código contém os scripts de geração e testes.

Este repositório é exclusivo da demonstração pública. Não carregar dados reais, credenciais ou configurações de produção. O painel oficial é um projeto separado e não é modificado por esta publicação.
